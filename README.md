# ₿ BTC-USD Price Forecasting Using Prophet

A time-series forecasting project that uses **Facebook Prophet** to analyze historical Bitcoin (BTC-USD) prices and generate a **90-day future price forecast**.

> ⚠️ **Disclaimer:** This project is for educational and exploratory purposes only. Cryptocurrency prices are highly volatile, and the predictions generated by this model should **not** be considered financial or investment advice.

---

## 📌 Project Overview

Bitcoin is one of the most volatile financial assets, making it an interesting subject for time-series analysis and forecasting.

In this project, historical **BTC-USD** price data was collected using `yfinance` and analyzed using **Prophet**, a time-series forecasting model designed to capture trends and recurring patterns in time-dependent data.

The objective was to:

* Collect historical Bitcoin price data
* Prepare the data for time-series forecasting
* Analyze long-term price trends
* Train a Prophet forecasting model
* Generate a **90-day forecast**
* Examine the predicted trend and uncertainty intervals
* Identify recurring patterns and interesting movements in the data

## 📊 Dataset

The project uses the **BTC-USD** ticker from Yahoo Finance.

The historical data is retrieved using:

```python
import yfinance as yf

btc = yf.Ticker("BTC-USD")
data = btc.history("max")
```

The downloaded dataset contains market information including:

* Open
* High
* Low
* Close
* Volume
* Dividends
* Stock Splits

## For forecasting, the **Closing Price** was selected as the target variable.

## 🔄 Data Preparation

Prophet expects the input dataset to contain two important columns:

| Column | Description       |
| ------ | ----------------- |
| `ds`   | Date/time         |
| `y`    | Value to forecast |

The BTC closing price was therefore converted into Prophet's required format:

```python
df = pd.DataFrame({
    "ds": data.index,
    "y": data["Close"]
})
```

## The timezone information was then removed from the date column to make it compatible with the forecasting workflow.

## 🤖 Forecasting Model

The project uses **Prophet** with its default configuration.

```python
from prophet import Prophet

m = Prophet()
m.fit(df)
```

After training the model, a future dataframe containing **90 additional daily observations** was generated:

```python
future = m.make_future_dataframe(
    periods=90,
    freq="D"
)

forecast = m.predict(future)
```

The forecast includes:

* `yhat` — Predicted value
* `yhat_lower` — Lower uncertainty bound
* `yhat_upper` — Upper uncertainty bound
* `trend` — Estimated underlying trend

---

## 📈 Forecast Output

The model generates both a point prediction and an uncertainty range.

For example, the generated forecast around **November 2026** shows predicted BTC prices around the **$96K–$97K range**, with a considerably wider uncertainty interval.

This illustrates an important characteristic of forecasting financial markets:

> A model can estimate a central trend, but the uncertainty around that prediction can still be substantial.

## 🔎 Observations

Based on the historical visualization and analysis performed during the project, several patterns were observed:

### 1. Long-Term Trend

Bitcoin has experienced multiple phases of strong growth, correction, and renewed upward movement.

The historical chart shows periods of relatively sustained growth followed by periods of considerably higher volatility.

### 2. Weekly Pattern

The analysis indicated recurring weekly movement in the series, with noticeable differences in the observed trend across days of the week.

However, these patterns should be interpreted cautiously because cryptocurrency markets operate continuously and are influenced by many external factors.

### 3. Yearly Movement

The yearly analysis suggested relatively limited movement during some parts of the year, followed by stronger movements and corrections during other periods.

The data also shows that Bitcoin's behavior can change significantly between different market cycles.

### 4. Future Trend

The forecast visualization extends the historical series into the future using Prophet's estimated trend and uncertainty intervals.

The future predictions appear considerably smoother than Bitcoin's historical price movements, highlighting one of the limitations of using a relatively simple forecasting approach for a highly volatile asset.

## ⚠️ Limitations

This project is intentionally simple and exploratory.

The model uses historical closing prices as its primary input and does not explicitly incorporate many factors that can influence Bitcoin prices, such as:

* Trading volume
* Market sentiment
* Macroeconomic indicators
* Interest rates
* News and geopolitical events
* On-chain metrics
* Technical indicators
* Market liquidity
* Sudden external shocks

Because of this, the forecast should **not** be interpreted as a reliable trading signal.
